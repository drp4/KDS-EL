A R T I C L E I N F O A B S T R A C T
Keywords: Crow search algorithm (CSA) is a metaheuristic algorithm inspired by the collective behavior of crows. It has
Feature selection been applied in various fields because of its fewer parameters and easy implementation. However, it has some
Crow search algorithm (CSA) drawbacks: (1) It is difficult to balance global search and local search, which leads to premature convergence. (2)
Time varying dynamic awareness probability
Local search and global search are too random, leading to the possibility of more invalid solutions. To address
Elite neighborhood search
such problems, this paper proposes the Elite Neighborhood Search and Dynamic Feature Probability-Guided
Feature probability
Crow Search Algorithm (NNS-DFPG-CSA) for feature selection. To address the difficulty of balancing global
search and local search, we propose a dynamic awareness probability based on time-varying to balance global
search and local search. To address the randomness of local search, we use the elite neighborhood search strategy
to guide the local search of crows. To address the randomness and low search efficiency of global search, we use
the feature probability to guide the global search of the algorithm. During the experiments, this paper uses 16
high-dimensional datasets and three evaluation metrics to evaluate NNS-DFPG-CSA. Experimental results show
that NNS-DFPG-CSA has satisfactory classification accuracy and feature subset length.
