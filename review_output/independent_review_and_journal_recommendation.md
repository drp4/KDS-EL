## 二、三位模拟审稿人独立评审

---

### 审稿人 A — 进化计算/群智能方向

**专业背景**：PSO、进化多目标优化、种群多样性理论

#### 整体印象

本文提出 DRS（多样性 Pareto 选择）+ KER（改进反馈权重学习）的双空间框架。实验规模令人印象深刻（15方法×20数据集），消融设计清晰。核心叙事（"第三种路径"——介于单目标 FS 和传统 MOFS 之间）具有概念吸引力。

#### 详细评分

| 维度 | 分数 | 理由 |
|------|:----:|------|
| 原创性 (20%) | **6/10** | 双空间互补框架的概念有新颖性，但每个组件（NHD 作为多样性指标、权重累加）都不是全新发明。关键创新是"组合方式"而非"新组件"。 |
| 方法严谨性 (25%) | **7/10** | 实验协议规范（StratifiedKFold 5×10 runs），统计检验完整（Wilcoxon+Friedman+Holm-Bonferroni）。但 DRS 的 Proposition 1（多样性下界）过于简单——NHD > 0 在任意有限种群大小下几乎必然成立，非平凡结论。Proposition 2（遍历性）因 rand_flip_p > 0 而平凡成立。 |
| 证据充分性 (25%) | **8/10** | 15 方法对比、五层消融、多维度评估（Acc+Feat+NHD+Time）。PCMAC 作为明星案例有说服力。消融边界条件诚实报告（3/25 反例）。 |
| 论证连贯性 (15%) | **7/10** | "第三种路径"叙事清晰，但随着消融数据展开，DRS 的边际贡献（+0.07pp Acc）和 KER 的净贡献（+0.79pp）都很小，主要增益来自 MI+Reinit（+3.89pp）。这削弱了"核心创新推动性能提升"的叙事。 |
| 写作质量 (15%) | **7/10** | 结构和关键数字组织良好。但"互补"替代"协同"的叙事痕迹较明显。 |
| **综合** | **7.05/10** | |

#### 主要问题

**Critical**: DRS 贡献的定位矛盾。文中说"DRS 的价值在 NHD 不在 Acc"，但如果 DRS 不提升 Acc，它的价值仅是"不拖累太多 Acc 的前提下增加多样性"——这在审稿人看来可能不够：一个在 88% 数据集上不损害性能、但仅贡献 +0.07pp 精度的多样性算子，其在算法中的必要性需要更强论证。

**Major**: VGS-MOEA 的三轴领先（Acc 0.9463 > 0.9450, Feat 51 < 220, Time 34s < 96s）对论文的核心竞争力构成质疑。作者区分"定长单解 vs 变长 Pareto 前沿"是合理叙事，但难掩在三个关键指标上全面落后的事实——特别是时间还慢 2.8 倍。

**Major**: KER 的 mechanism 在技术上很简单：`weight += delta`。虽然"跨迭代累积"是新颖点，但一个审稿人问"这和一个带衰减的记忆向量有什么本质区别？"就很难回答。需要更深入的理论分析。

#### 审稿人置信度

高 — 该领域的多样性维护和 PSO 变体是我的核心研究方向。

### 审稿人 B — 特征选择/生物信息学方向

**专业背景**：高维生物标志物选择、wrapper 方法、生物医学应用

#### 整体印象

本文解决了高维生物信息学特征选择中的两个实际困境（种群同质化和知识浪费），实验设计严谨。作为偏应用的方法论文，有明确的实际价值。

#### 详细评分

| 维度 | 分数 | 理由 |
|------|:----:|------|
| 原创性 (20%) | **6/10** | 改进反馈学习（KER）在实践中可能有用，但技术上不深。方法的增量性质明显——MEL 基线已发表，DRS 是 EMDO 改名，KER 是 KGEF 改名。名称和叙事变化无法掩盖核心组件的渐进性质。 |
| 方法严谨性 (25%) | **7/10** | 实验协议规范，KNN 分类器选择合理。但只有一种分类器（KNN）的验证是局限——在生物信息学中，SVM/RF 也是常见选择。 |
| 证据充分性 (25%) | **8/10** | 20 数据集的覆盖范围好（n∈[36,2600], d∈[500,54675]）。生物标志物发现场景的特征压缩（-91.9%）有实际意义。天花板效应已诚实讨论。 |
| 论证连贯性 (15%) | **6/10** | "第三种路径"的叙事在消融数据面前显得僵硬：如果 DRS 的精度贡献近乎零，那么双空间框架的必要性需要更直接的证据（如 PCMAC）。仅靠一个数据集支撑互补论据说服力有限。 |
| 写作质量 (15%) | **7/10** | 组织良好。 |
| **综合** | **6.85/10** | |

#### 主要问题

**Critical**: 从生物信息学应用的角度，方法在困难数据集（ALL2, ALL3, Stroke）上反而比基线 MEL 更差。作者归因于"DRS 过度多样性"，但这恰恰是该方法在最具挑战性的场景中失效的证据。如果方法在最需要特征选择的困难小样本数据集上退化，应用价值受到质疑。

**Major**: 只有 KNN 一种分类器。生物信息学中常见使用 SVM 或 RF 作为 wrapper 分类器。仅用 KNN 可能过于简化——KNN 对特征缩放和维度更敏感。

**Major**: 20 数据集中多分类仅 4 个（CNS-3, SRBCT-4, COIL20-20, ISOLET-26），且在两个多分类数据集（ISOLET, COIL20）上方法表现最差。对多分类场景的适用性存疑。

**Minor**: 特征压缩（-91.9% vs MEL）的基线 MEL 选 2722 个特征本身就很多。如果基线的特征选择已经较差，百分比改善可能夸大实际效果。

#### 审稿人置信度

中高 — 我主要做生物信息学特征选择应用，对 EC 方法细节不是最深。

### 审稿人 C — 进化多目标优化/MOFS 方向

**专业背景**：MOEA/D、NSGA-II、VGS-MOEA、MOFS 前沿方法

#### 整体印象

本文试图在单目标 FS 和多目标 FS 之间开辟"第三种路径"。概念上有意思，但在执行层面，我看到的问题是双空间框架与标准 MOFS 之间的界限模糊——DRS 本身就是合法的双目标 Pareto 优化，为什么要用"辅助目标"来重新包装？

#### 详细评分

| 维度 | 分数 | 理由 |
|------|:----:|------|
| 原创性 (20%) | **6/10** | "NHD 作为辅助目标"的概念在 MOFS 文献中不是全新的——多样性维持是 MOEA 的基础设计原理。不同之处在于 DRS 的 quadratic α_cd 调度，但这更像调参技巧而非理论贡献。 |
| 方法严谨性 (25%) | **8/10** | 实验设计好——6 个 MOFS 方法覆盖了三代代差（经典/混合/变长），这是我在审 MOFS 论文时希望看到的。对比框架公正。 |
| 证据充分性 (25%) | **7/10** | 对比数据完整。但 VGS-MOEA 比 KDS-EL 在三个指标上都好——作者处理为"不同范式"，但这个区分在 MOFS 文献中不是硬性界限。变长 MOEA 也可以输出单一解（通过选择 knee point 或最小特征子集）。 |
| 论证连贯性 (15%) | **6/10** | 双空间叙事与 MOFS 的界限划分不够有说服力。"输出单一最优解"并不是一个足够强的区分——许多 MOFS 论文同样建议用户从 Pareto 前沿选择一个解。 |
| 写作质量 (15%) | **7/10** | 标准学术写作。 |
| **综合** | **6.85/10** | |

#### 主要问题

**Critical**: 核心定位问题——本文的"第三种路径"（单解输出 + 辅助目标）与 MOFS 的本质区别是什么？当 DRS 做 NSGA-II Pareto 排序时，它就是一个多目标选择算子。说"KDS-EL 不是 MOFS"可能在 MOFS 研究者看来是语义游戏。需要更精确的技术界定——比如：NHD 不作为最终用户优化目标，仅作为搜索正则化器——但这个区分是否足够强健？

**Major**: VGS-MOEA 的优势被我严重关切。KDS-EL 排名 #2，落后 VGS-MOEA。在 EC 论文中，提出的方法比 5 年前的方法差，且是在几乎所有指标上差，这不是一个小问题。作者的"定长 vs 变长"区分是真实的，但审稿人可能不接受。

**Major**: DRS 中使用 NSGA-II 的合理性未经论证。为什么是 NSGA-II（拥挤距离）而非其他选择策略？α_cd 调度的 (t/T)² 是否有理论依据还是直觉选择？

**Minor**: 建议作者考虑将 KDS-EL 明确定位为"多样性正则化的单解 FS 方法"，而不是试图在 SO-FS 和 MO-FS 之间画一个硬性界限。

#### 审稿人置信度

高 — MOFS 是我的核心研究方向。

## 三、论文核心优缺点总结

### 优点

1. **实验规模扎实**：15 方法 × 20 数据集 × 10 次 = 3000+ 运行，统计检验完整（Wilcoxon + Friedman + Holm-Bonferroni）
2. **消融设计清晰**：五层消融（MEL → MEL_MI → DRS → KER → Full），架构完整
3. **诚实讨论局限**：天花板效应、边界条件（3/25 反例）、VGS-MOEA 领先均正面讨论
4. **特征压缩显著**：-91.9% vs MEL，在生物标志物发现场景有实际价值
5. **概念创新点存在**：双空间互补框架（结构空间 + 适应度空间）的叙事有差异化价值

### 缺点

1. **组件贡献小而核心创新弱**：KER 净 +0.79pp、DRS 净 +0.07pp，主要增益（+3.89pp）来自 MI+Reinit（非创新）
2. **定位模糊**：与 MOFS 的区分不够清晰，可能被质疑为"NSGA-II 加了一个新目标"的重新包装
3. **VGS-MOEA 全面领先**：排名 #2 且有差距（特别在特征数和时间上差距大），降低论文的竞争力
4. **理论深度不足**：Proposition 1 和 Proposition 2 均为平凡结论
5. **KER 机制简单**：`weight += delta` 的实现过于直接，缺乏理论分析
6. **叙事调整痕迹**：从"协同"到"互补"的转变为时较晚，可能影响叙述的一致性和作者信心

### 首选推荐：Swarm and Evolutionary Computation (SWEVO)

**匹配理由**：
- 主题完全对齐——PSO、群智能、进化特征选择正好是 SWEVO 的核心范围
- SWEVO 对方法论文的要求是"充分实验验证 + 合理的创新增量"——KDS-EL 有 15 方法 × 20 数据集 × 10 runs，实验规模满足要求
- SWEVO 对"互补框架"类论文接受度高于纯新算法论文
- IF ~9.5，属于 EC 领域 Tier 1~2 之间的高质量期刊

**需要做的准备**：
1. 强化与 MOFS 的定位区分的理论论证
2. 补充至少一种其他分类器（SVM 或 RF）的实验
3. 对 VGS-MOEA 的对比做更详细的叙事（不作为竞争者，而是不同范式）
4. 强化 DRS 必要性的实证论证

**投稿建议策略**：
- 正文：主表 10 方法 × 20 数据集
- 补充材料：完整 15 方法 + 额外分类器实验 + 参数敏感性分析
- Cover Letter 中强调"第三种路径"概念定位，明确区分于 MOFS

### 次选推荐：Information Sciences (INS)

**匹配理由**：
- 范围宽，对特征选择方法论文接受度好
- 对"工程贡献 + 实验充分"的论文接受度高于纯理论创新要求
- 审稿速度相对较快（平均 6-8 周）

### 安全推荐：Expert Systems with Applications (ESWA)

**匹配理由**：
- 应用导向，对理论深度要求最低
- 实验充分（3000+ runs）是最强卖点
- 审稿速度较快
- 接受率 ~20-25%，相对友好

### 关于 IEEE TEVC 的判断

**不推荐作为首选目标**。原因：
1. IEEE TEVC 的接受率 ~10-12%，且倾向于有强理论贡献的论文
2. Proposition 1 和 2 的平凡性在 TEVC 审稿人眼中是明显弱点
3. VGS-MOEA 在三个指标上全面优于 KDS-EL 会严重削弱 TEVC 审稿人的信心
4. TEVC 是 EC 领域顶刊——审稿人通常是该领域最有经验的研究者，会迅速识别出 DRS 不是全新技术发现

理论上可在上述三个首选期刊被拒后考虑尝试 TEVC，建议先投稿 SWEVO 或 INS。

## 五、最终评估结论

| 维度 | 评级 |
|------|:----:|
| **论文整体水平** | **中等偏上**（7/10） |
| **理论创新深度** | **中等**（缺乏强理论贡献） |
| **实验充分性** | **优秀**（15方法×20数据集×10次） |
| **实际应用价值** | **较高**（特征压缩显著，生物标志物发现场景有价值） |
| **出版可行性** | **高**（在 Tier 2 期刊上接收可能性大） |
| **顶级期刊潜力** | **低**（理论深度不足，对比方法全面领先的问题难以在顶级期刊审稿中过关） |

**一句话总结**：KDS-EL 是一篇实验扎实、工程贡献明确的中等偏上水平论文。双空间互补框架的概念有亮点，但每个组件的独立贡献较小，理论深度不足。推荐投稿 **Swarm and Evolutionary Computation** 或 **Information Sciences** 或 **Expert Systems with Applications**，在这些期刊上有较高的接受概率。
