## 二、参考论文结构对照

| 论文 | 结构 |
|---|---|
| MI-MPODE (ESWA 2024) | 1 Intro → 2 Background (DE/MI/OBL) → 3 Proposed (3.1–3.5) → 4 Experimental results and analysis (4.1 Datasets, 4.2 Settings, 4.3 Results, 4.4 Statistical tests, 4.5 Ablation) → 5 Conclusion |
| NNS-DFPG-CSA (ESWA 2025) | 1 Intro → 2 Related work → 3 Proposed (framework/init/strategies) → 4 Experimentation and discussion (4.1 Datasets, 4.2 Parameters, 4.3 Metrics, 4.4 Overall performance 含组件有效性/参数敏感性) → 5 Conclusion |
| TVESCSO (ESWA 2025) | 1 Intro → 2 Related work → 3 SCSO 背景 → 4 Proposed (框架/复杂度) → 5–7 实验 → 8 Conclusion |
| EMSWOA (ASC 2024) | 1 Intro → 2 Related work → 3 Proposed (framework/机制/fitness/复杂度) → 4 Experimental results and discussion (4.1 Setup, 4.2 分析) → 5 Conclusion |

**共同模式**：Intro → Related/Background → Proposed（含框架图 + 伪代码 + 复杂度）→ **一个 Experiments 大章**（设置/指标 → 主结果 → 统计 → 消融 → 参数）→ Conclusion。单目标方法论文很少把消融、参数敏感性独立成章。

## 五、后续重写注意（按“方法→实验→结果→文献→引言→摘要”）

1. **单目标定位**：KDS-EL 是单目标（加权标量化）方法，全文按单目标叙述；5 个 MOFS 只作为对比基线（参考论文同样会对比 MO 类方法），不再与单目标方法并列为主线。相关工作里 MOFS 小节可压缩。
2. **实验章按参考论文惯例**：先数据集表 T2、对比方法表 T1、参数表 T3，再给出指标定义（准确率 / 选择率 / 运行时间）。
3. **统计检验**：T6 + T6b 双表支撑，热图入附录；天花板数据集分析保留在 5.5。
4. **消融与参数**：作为 5.8、5.9 小节（减法读法 + 单因素扰动），不独立成章。
5. **数字口径**：以 `paper/authoritative_numbers.md` 为准（0.9574 / 87.8 特征 / +3.97pp / +4.42pp / 3.4×）。
6. **复杂度分析**：04 节 4.7 已有，保留在方法章内。
