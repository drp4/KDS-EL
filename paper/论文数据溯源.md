# KDS-EL 论文数据溯源与对比手册

> 用途：记录论文中出现的所有数据分别来自哪个文件、哪批实验、哪个生成脚本，并给出复核方法，避免后续改稿时混入旧口径或错误数字。
> 最后核对：2026-08-06
> 论文唯一数字口径：**20-DS（20 个共同数据集）**，14 个定长方法。

---

## 1. 权威口径与文件关系

### 1.1 一句话口径

- 论文聚合数字一律使用 20 个共同数据集：ALL1, ALL4, ALL_AML, Adenoma, BASEHOCK, COIL20, Colon, DLBCL, Gastric, Gastric1, Gastric2, ISOLET, Leukaemia, Lymphoma, Myeloma, PCMAC, Prostate, SRBCT, T1D, madelon。
- 最终事实源是各实验目录里的 `results_detail.csv`（10 次独立运行的逐次原始记录）。
- `results_summary.csv` 是 `run_formal_experiment.py` 从 detail 重算的每数据集 Mean/Std。
- `output/tables/*.csv` 是 `code/generate_tables.py` 从 summary/detail 合并生成。
- `output/tables/*.tex` 是 `paper/_gen_tables.py` 从上述 CSV 和 `output/实验数据汇总.md` 生成，禁止手改。
- `output/实验数据汇总.csv` 与 `output/实验数据汇总.md` 是同源的两份平行汇总：CSV 是 Sections 1-10 的纯表格版，便于脚本/表格读取；MD 另含第 11 节参数敏感性。CSV 与 MD 不一致时，以原始 `results_detail.csv` 重算为最终证据。
- `paper/authoritative_numbers.md` 是写正文时使用的唯一权威数字摘要。
- `记忆文档.md` 的「## 一、实验目录总览」与「### 数据有效性说明」是**使用任何 `results_detail.csv` 前必须核对的有效性登记表**：哪些目录有效、哪些目录已废弃、同一目录内哪些 Version 能取，都以它为准。

使用优先级：**写正文只引用 `paper/authoritative_numbers.md`；做表格/图先查 `output/实验数据汇总.md` 与 `output/实验数据汇总.csv`；三者任何一处冲突，都用原始 `results_detail.csv` 重算裁决。**
取原始数据前先查 `记忆文档.md` 的有效性表，禁止直接从废弃目录或旧 Version 取数。

### 1.2 文件地图

```text
记忆文档.md ← 实验目录总览 + 数据有效性说明（读 results_detail.csv 前必查）

datasets/*.txt, *.mat
    └─ code/utils.py (load_dataset)
        └─ code/run_formal_experiment.py
            ├─ output/<实验目录>/results_detail.csv   ← 原始逐次数据
            └─ output/<实验目录>/results_summary.csv  ← 每数据集 Mean±Std
                    └─ code/generate_tables.py
                        └─ output/tables/T4..T7, T6b 等 CSV
                            └─ paper/_gen_tables.py
                                └─ output/tables/*.tex → paper/main.tex

output/实验数据汇总.md  ← 人工维护的汇总文档（Sections 1-11，含参数敏感性）
output/实验数据汇总.csv ← 与 MD 同源的纯表格版（Sections 1-10 + 废弃内容记录）
paper/authoritative_numbers.md ← 写正文唯一引用数字（冲突时以 results_detail.csv 重算裁决）
```

## 6. 运行时间数字的生成口径

- 运行时间最终口径：各实验目录 `results_detail.csv` 的 `Time_sec` 直接平均后四舍五入到 1 位小数。
